# 🏙️ Análisis de Datos Urbanos de Bogotá

Proyecto de análisis de datos abiertos de infraestructura urbana de Bogotá usando Python y pandas.

## 📊 Datos

| Archivo | Registros | Descripción |
|---------|-----------|-------------|
| Historico_PM10.xlsx | 86 | Concentración de material particulado (2012-2023) |
| Historico_IV.xlsx | 340 | Índice de vulnerabilidad por localidad (2007-2023) |
| Historico_UMV.xlsx | 1,674 | Mantenimiento vial UMV (2017-2018) |
| Historico_IntervencionesIDU.xls | 41,019 | Intervenciones IDU (2020-2025) |

## 🐍 Scripts

- `explorar_pm10.py` - Exploración de calidad del aire
- `analisis_vulnerabilidad.py` - Análisis de vulnerabilidad por localidad
- `resumen_mantenimiento_vial.py` - Resumen de intervenciones viales

## 🛠️ Instalación

```bash
pip install pandas openpyxl xlrd
```

## ▶️ Ejecución

```bash
python explorar_pm10.py
python analisis_vulnerabilidad.py
python resumen_mantenimiento_vial.py
```
